# 菜鸡修仙传

纯文字 MUD 放置修仙 · 网页小游戏。无需后端，打开网址即玩，进度保存在浏览器本地。

## 玩法

- **挂机离线攒资源**：在线/离线都会产出修为、铜钱、琼浆玉液、灵气。
- **回合文字策略战斗**：速度、控制（眩晕/冰冻/沉默）、治疗、五行克制决定胜负，可用策略以弱胜强。
- **境界渡劫**：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫，渡劫失败损失 10% 修为，备渡劫丹提升成功率。
- **四大种族**：人族（控制）、魔族（爆发）、龙人族（肉盾）、精灵族（续航）。
- **仙府经营**：灵脉、灵根、法阵、聚灵阵、醉月樽、功法、造化乾坤殿（炼丹/炼器）。
- **伙伴抽卡**：蓝→紫→金→红；多余伙伴进聚灵阵加成全队。
- **装备法宝**：强化/精炼/附魔/套装；水月洞天刷法宝碎片合成。
- **副本**：主线成仙之路、水月洞天、五行山、每日副本扫荡。
- **仙宝阁**：普通集市、鸿蒙紫气阁、五行天坊。

## 部署（GitHub Pages）

1. 在 GitHub 生成一个 Personal Access Token（勾选 `repo` 权限）。
2. 运行 `deploy.ps1` 并设置 `GITHUB_TOKEN` 环境变量。
3. 完成后访问 `https://<你的用户名>.github.io/caiji-xiuxian-zhuan/`。

也可把整个 `index.html`、`css/`、`js/` 上传到任意静态托管（Netlify Drop、静态.app 等）。
